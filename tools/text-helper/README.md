# 글손질 — 글자수 · 맞춤법 · 텍스트 정리

브라우저에서 바로 쓰는 한국어 글쓰기 보조 도구입니다. 서버가 없고, 입력한 글은 기기 밖으로 나가지 않습니다.

| 기능 | 내용 |
|---|---|
| 글자수 | 공백 포함 / 공백 제외 / 줄바꿈만 제외 / 바이트(UTF-8) / 바이트(한글 2B, 채용 사이트 방식) / 단어 / 문장 / 줄 / 문단 / 원고지 매수 / 읽는 시간 |
| 목표 | 목표 수치와 기준(공백 포함·제외·바이트)을 정하면 진행률과 남은·초과 수치를 표시. 자소서 500자 제한 같은 용도 |
| 맞춤법 점검 | 약 300개 규칙(맞춤법·띄어쓰기·외래어·어미)으로 자주 틀리는 표현을 본문에 표시. 항목별 적용 / 무시, "확실한 항목 모두 적용" |
| 정리 도구 | 연속 공백 정리, 빈 줄 제거, 줄바꿈 합치기, 문장마다 줄바꿈, 중복 줄 제거, 정렬, 따옴표·전각 문자 정리 등. 모두 되돌리기 가능 |
| 찾기·바꾸기 | 정규식·대소문자 옵션, 일치 수 표시, 다음 찾기 / 선택 바꾸기 / 모두 바꾸기 |
| 그 밖에 | 자동 저장(localStorage), 밝게/어둡게 테마, 텍스트 파일 열기·끌어놓기, 오프라인 동작(PWA), 설치 가능 |

## 실행

빌드 과정이 없습니다.

```bash
# 그냥 파일을 열어도 됩니다
open tools/text-helper/index.html

# 또는 아무 정적 서버로 (PWA·오프라인 캐시는 http(s)에서만 동작)
python3 -m http.server 8080 --directory tools/text-helper
```

GitHub Pages·Netlify 같은 정적 호스팅에 `tools/text-helper/` 폴더를 그대로 올리면 됩니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면과 스타일 |
| `app.js` | 통계·점검 엔진·정리 도구·찾기바꾸기·UI |
| `rules.js` | 맞춤법 규칙 데이터. **규칙 추가는 여기만** |
| `check-rules.mjs` | 규칙 회귀 검사 (`node tools/text-helper/check-rules.mjs`) |
| `manifest.webmanifest`, `sw.js`, `icon.svg` | PWA(설치·오프라인) |

## 규칙 추가하기

`rules.js`의 `RULES` 배열에 한 줄을 더합니다.

```js
{ re: /몇일/g, to: '며칠', cat: 맞, note: '"몇일"은 쓰지 않습니다. 언제나 "며칠"입니다.' },
```

- `re`는 반드시 전역(`g`) 정규식. `to`는 문자열(`$1` 치환 가능) 또는 `(match, ctx) => string | null` 함수(`null`이면 건너뜀).
- `sure: false`를 주면 "확인 필요"(주황)로 표시되고 "모두 적용"에서 제외됩니다. 문맥에 따라 맞을 수도 있는 표현에 씁니다.
- 규칙은 위에서부터 적용되고, 이미 잡힌 구간과 겹치는 뒤 규칙은 무시됩니다. 구체적인 규칙을 앞에 두세요.
- 규칙을 넣었으면 `check-rules.mjs`의 `CASES`에 잡혀야 할 예와 **잡히면 안 되는 정상 문장**을 함께 추가하고 검사를 돌립니다.

## 한계와 기준

- 사전 없는 규칙 기반이라 문맥을 이해하지 못합니다. 모든 오류를 잡지 못하고, 제안이 틀릴 수도 있습니다. 최종 판단은 글쓴이의 몫입니다.
- 기준: 국립국어원 「한글 맞춤법」·「표준어 규정」·「외래어 표기법」, 표준국어대사전.
- 글자수는 유니코드 코드 포인트 단위입니다. 사이트마다 세는 방식이 달라(이모지·결합 문자·줄바꿈 처리) 1~2자 차이가 날 수 있습니다.
