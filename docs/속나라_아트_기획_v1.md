# 《속나라》 아트 기획 v1 — 그래픽 방향과 로드맵

> **프레이밍(§0, 비협상):** 이 게임은 은유적 경험이며 의료 조언이 아니다. 아트도 이 원칙을 지킨다 —
> 질병은 괴물이 아니라 **불균형**, 균은 적이 아니라 **몸을 돕는 생명**. 우울·암 등 민감 소재는
> 존엄·희망의 방향으로만. 유혈·공포·의료 사진식 묘사, 실제 브랜드/제품/치료·상담번호 일절 없음.

## 1. 확정된 방향 (사용자 결정)

| 항목 | 결정 | 근거 |
|---|---|---|
| **아트 스타일** | 플랫 벡터 "생태화(生態畵)" | 부드러운 유기 곡선 + 오행 팔레트. SVG라 라이트/다크·고해상도·Capacitor CSP 모두 대응, 현재 미니멀 UI와 연속. |
| **생산 방식** | 플레이스홀더 먼저 → 나중 교체 | 슬롯을 지금 다 채워 "있어 보이게", 스타일 확정 후 진짜 아트로 무손실 교체. |
| **첫 착수** | 히어로 유닛 10종 | 가장 게임다운 수집형 마스코트. 손맛 즉시 체감. §0 부담도 적어 스타일 검증에 최적. |

## 2. 컨셉 — "몸속을 하나의 살아있는 자연으로"

- **균/유닛 = 마스코트 세포**: 둥근 유기체 몸 + 순한 얼굴 + 섬모. 밝고 존엄하게.
- **질병/보스 = 흐트러진 풍경**: 막힘·쌓임·꺼짐. "적"이 아니라 되돌릴 불균형.
- **오행 6월드 = 각기 다른 생태**: 목·화·토·금·수·상화를 팔레트로 분리.

## 3. 플레이스홀더 아트 시스템 (구현 완료 — G1)

`src/game/art.ts` — 유닛 id로 **결정론적** 생성하는 플랫 벡터 마스코트.

- **결정론적**: id 해시 → 시드(mulberry32). 렌더마다 동일한 모습.
- **오행 팔레트**: 절제된 생태 hue 10종에서 결정론적 선택(라이트/딥/글로우 자동 파생).
- **희귀도 표현**(한눈에 읽힘):
  - common: 순한 몸 + 섬모 3
  - rare: 윤곽 디테일↑ + 섬모 4
  - epic: 은은한 오라 링 + 섬모 6
  - legendary: 금빛 후광 + 왕관 점(위엄) + 섬모 8
- **얼굴**: 항상 순한 두 눈 + 미소 (마스코트, 공포 없음 — §0).
- **수집 연출**: 미보유 유닛은 로스터에서 **흑백 실루엣**(`grayscale`), 보유 시 채색 → "모으면 드러난다" 손맛.

### 교체 방법 (플레이스홀더 → 진짜 아트)
`content/units.ts` 의 유닛에 `art: "<svg …>…</svg>"` 필드를 넣으면 **그게 우선**한다.
아무 것도 없으면 `art.ts` 가 자동으로 마스코트를 그린다. → 렌더러 1개 유지, 데이터만 교체.
엔진·UI 코드 변경 0줄로 한 종씩 승격 가능.

## 4. §0 아트 가드레일 (전 그룹 공통)

- **우울** → 괴물 아님. 회색 안개·무거운 공기가 손길로 걷히며 **색이 돌아오는** 연출.
- **암** → 유혈/공포 아님. 은신형답게 조용히 번지는 엉킨 그림자, 감시(물길)로 드러나는 형태.
- **숙주 초상** → 증상 전시 X. 실루엣 + 표정/분위기로 **회복 컷**(창을 여는, 아이를 안는)을 전달.
- 승리 화면은 "스스로 균형을 회복" 프레임 유지. 상시 디스클레이머 노출.

## 6. 기술 원칙

- **인라인 SVG only** (외부 fetch 0) → Capacitor 엄격 CSP 안전.
- **테마 대응**: 색 도형/투명 배경이라 라이트·다크 모두 자연.
- **데이터 주도**: 아트는 `art` 필드로. 새 유닛/보스 추가 시에도 렌더러 불변.
- 리치화가 필요하면 스프라이트 아틀라스(WebP) + 지연로딩으로 확장(엔진 무관).
