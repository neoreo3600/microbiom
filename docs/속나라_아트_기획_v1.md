# 《속나라》 아트 기획 v1 — 그래픽 방향과 로드맵

> **프레이밍(§0, 비협상):** 이 게임은 은유적 경험이며 의료 조언이 아니다. 아트도 이 원칙을 지킨다 —
> 질병은 괴물이 아니라 **불균형**, 균은 적이 아니라 **몸을 돕는 생명**. 우울·암 등 민감 소재는
> 존엄·희망의 방향으로만. 유혈·공포·의료 사진식 묘사, 실제 브랜드/제품/치료·상담번호 일절 없음.

## 1. 확정된 방향 (사용자 결정)

| 항목 | 결정 | 근거 |
|---|---|---|
| **아트 스타일** | 플랫 벡터 "생태화(生態畵)" | 부드러운 유기 곡선 + 오행 팔레트. SVG라 라이트/다크·고해상도·Capacitor CSP 모두 대응, 현재 미니멀 UI와 연속. |
| **생산 방식** | 플레이스홀더 먼저 → 나중 교체 | 슬롯을 지금 다 채워 "있어 보이게", 스타일 확정 후 진짜 아트로 무손실 교체. |
| **첫 착수** | 히어로 유닛 10종 | 가장 게임다운 수집형 마스코트. 손맛 즉시 체감. §0 부담도 적어 스타일 검증에 최적. |

## 2. 컨셉 — "몸속을 하나의 살아있는 자연으로"

- **균/유닛 = 마스코트 세포**: 둥근 유기체 몸 + 순한 얼굴 + 섬모. 밝고 존엄하게.
- **질병/보스 = 흐트러진 풍경**: 막힘·쌓임·꺼짐. "적"이 아니라 되돌릴 불균형.
- **오행 6월드 = 각기 다른 생태**: 목·화·토·금·수·상화를 팔레트로 분리.

## 3. 플레이스홀더 아트 시스템 (구현 완료 — G1)

`src/game/art.ts` — 유닛 id로 **결정론적** 생성하는 플랫 벡터 마스코트.

- **결정론적**: id 해시 → 시드(mulberry32). 렌더마다 동일한 모습.
- **오행 팔레트**: 절제된 생태 hue 10종에서 결정론적 선택(라이트/딥/글로우 자동 파생).
- **희귀도 표현**(한눈에 읽힘):
  - common: 순한 몸 + 섬모 3
  - rare: 윤곽 디테일↑ + 섬모 4
  - epic: 은은한 오라 링 + 섬모 6
  - legendary: 금빛 후광 + 왕관 점(위엄) + 섬모 8
- **얼굴**: 항상 순한 두 눈 + 미소 (마스코트, 공포 없음 — §0).
- **수집 연출**: 미보유 유닛은 로스터에서 **흑백 실루엣**(`grayscale`), 보유 시 채색 → "모으면 드러난다" 손맛.

## 3-b. 오행 월드 배경 (구현 완료 — G2)

`worldBackdrop(element)` — 보스전 무대에 그 월드의 오행 생태 풍경을 깐다.

- **오행별 팔레트+모티프**: 목=숲 능선·나무·반딧불 / 화=화로 빛·피어오르는 불씨 / 토=층층 대지·곡물 /
  금=옅은 안개 띠 / 수=깊은 물결·기포 / 상화=신경·림프 오로라 망.
- **가독성 우선**: 낮은 투명도 + 하단 페이드. 카드/텍스트는 불투명 패널이라 그대로 읽힘.
- **§0 준수**: 은유적 풍경만, 공포·의료 묘사 없음.
- 보스전 탭에서만 표시(`render()`가 encounter 월드로 자동 선택). 카드 뒤 `z-index` 레이어.

### 교체 방법 (플레이스홀더 → 진짜 아트)
`content/units.ts` 의 유닛에 `art: "<svg …>…</svg>"` 필드를 넣으면 **그게 우선**한다.
아무 것도 없으면 `art.ts` 가 자동으로 마스코트를 그린다. → 렌더러 1개 유지, 데이터만 교체.
엔진·UI 코드 변경 0줄로 한 종씩 승격 가능.

## 3-c. 보스 은유 형상 (구현 완료 — G3)

`bossEmblem({id, element, behavior})` — 질병 = 괴물이 아니라 **불균형 문양(sigil)**. 얼굴·생물 아님.
element 팔레트의 링(돌보는 몸) 안에 그 보스의 **실제 게이지 거동**을 은유로 담는다.

| 보스 | 문양 은유 | 게이지 거동 반영 |
|---|---|---|
| 2형 당뇨 | 차오르는 단 물결 + 결정 | 혈당 fill(넘침) |
| 류마티스(자가면역) | 안으로 향한 과열 화살 + 뜨거운 핵 | 공격=자해·실열(heatPolarity −1) |
| 우울 | 회색 안개 + **꺼지지 않는 작은 빛** | 안개 fill · §0 희망 |
| 대장암 | 조용한 엉킴(그림자) + **지켜보는 감시광** | 종양 stealthGrow · 관해(감시유지) |
| 지방간 | 무겁게 가라앉는 침전 | 간지방 fill(쌓임) |
| 불안·공황 | 가라앉지 않는 물결 + **고요한 중심** | 과각성 fill · §0 희망 |

- **§0 핵심**: 민감 보스(우울·암·불안)엔 반드시 "꺼지지 않는 것"(빛·감시·고요한 중심)을 심어 **희망의 방향**을 시각적으로 고정. 공포·유혈·의료 묘사 전무.
- 보스전 헤더에 "불균형 아바타"로 표시(숙주 옆). 보스 교체 시 자동 갱신.

## 4. §0 아트 가드레일 (전 그룹 공통)

- **우울** → 괴물 아님. 회색 안개·무거운 공기가 손길로 걷히며 **색이 돌아오는** 연출.
- **암** → 유혈/공포 아님. 은신형답게 조용히 번지는 엉킨 그림자, 감시(물길)로 드러나는 형태.
- **숙주 초상** → 증상 전시 X. 실루엣 + 표정/분위기로 **회복 컷**(창을 여는, 아이를 안는)을 전달.
- 승리 화면은 "스스로 균형을 회복" 프레임 유지. 상시 디스클레이머 노출.

## 5-b. 디자인 폴리시 트랙 (아트 에셋과 별개 — "게임다움")

"구려 보임"의 약 70%는 아트가 아니라 **디자인 시스템·연출** 문제 → 코드로 무료 해결.
목표 톤: **아기자기 캐주얼(둥글·마스코트)**. 폴리시 먼저, 그 위에 실제 아트를 얹는다.

| 단계 | 내용 | 상태 |
|---|---|---|
| **P1** | 디자인 시스템 — 토큰(따뜻한 색·라운드·깊이·타이포) + 전 화면 리스타일 | ✅ 완료 |
| **P2** | 게임 저스 — 플로팅 텍스트·탭 파티클·오버슛 바·페이즈/승리 연출·사운드(Web Audio) | ✅ 완료 |
| **P3** | 히어로 유닛 고품질 벡터 캐릭터 일러스트(음영·표정·소품) | ✅ 완료 |
| **P4/G6** | 배경·보스도 동급 일러스트로 심화 + (원하면) 라스터 AI 아트 | ⬜ |

**P1 상세:**
- CSS 변수 토큰화(`--bg/--surface/--ink/--radius/--mint…`) → 전 화면 일관.
- 따뜻한 코지 다크 팔레트(차가운 슬레이트 → 웜 뉴트럴) + 캔디 파스텔 액센트.
- 둥근 청키 버튼(순·정·재 = 3D 베벨 캔디, 아이콘 💧🫧🌱), 알약형 미터/게이지, 깊이(소프트 섀도).
- 놀이감 있는 라운드 폰트(**Jua**) — 타이틀·버튼·숫자에. 본문은 Noto Sans KR.
- 라운드 탭바(액티브 아이콘 리프트), 오버레이 블러.
- 엔진/HTML 구조 무변경 — 스타일링만. 기존 아트(마스코트·배경·문양)와 조화.
- (참고) 폰트는 현재 Google Fonts 링크. Capacitor 오프라인 배포 시 woff2 서브셋 번들 필요.

**P2 상세 (`src/game/juice.ts` — 에셋 0, 전부 합성):**
- **사운드**: Web Audio 합성 SFX(오실레이터 엔벨로프) — 순환/정화/재생 각기 다른 음색, 페이즈 전진 상승 아르페지오, 승리 5음 화음, 막힘음. 첫 제스처에 오디오 컨텍스트 resume. 좌상단 🔊 뮤트 토글(localStorage 저장).
- **탭 피드백**: 손길 탭 시 버튼 지점에서 파티클 버스트 + 위로 떠오르는 플로팅 텍스트("💧 물길·온기 ▲" 등).
- **바 연출**: 미터/게이지 폭 전환에 오버슛 이징(cubic-bezier), 변경 시 플래시.
- **페이즈/승리 연출**: 순→정→재 전진 시 상승음+스파클, 항상성 복원 시 승리 화음+컨페티(1회 발화 감지).
- **접근성**: `prefers-reduced-motion` 이면 파티클/컨페티 생략(소리·플로팅 최소 유지).
- Web Animations API로 자동 정리(onfinish 시 DOM 제거) — 누적 없음.

## 5-c. P3 실제 아트 — 히어로 캐릭터 일러스트 (완료)

**AI 라스터 생성 경로 판단:** 연결된 Hugging Face에 이미지 생성 Space(FLUX·Qwen)는 있으나
현재 세션은 `invoke` 비활성(gradio=none)이라 **실제 생성 불가**. → 확실히 되는 길로 전환:
내가 완전히 통제하는 **고품질 벡터 캐릭터 일러스트**(수많은 상용 캐주얼 게임이 쓰는 정식 아트 스타일).

`unitAvatar` 재작성 — 단순 블롭 → 캐릭터 디자인:
- **음영**: 몸통 그라디언트 + 배(belly) 하이라이트 + 림라이트 + 바닥 그림자 → 입체감.
- **표정**: 광택 눈(하이라이트 2점)·볼터치·미소. 유닛별 눈 변형(happy/calm/alert/sparkle).
- **의미 있는 실루엣·소품**(랜덤 아님, 의도 배정): 락토=캡슐+잎 · 비피도=쌍구체 · 아커만시아=점액 스카프 ·
  부티레이트=번개 · NK=바이저+경계 눈 · Treg=후광+평온 눈 · 사이코=파장 · 공생체=티어드롭+나선 ·
  정점=왕관+오라 · 불멸=이리데센트 후광+반짝이.
- **교체 구조 유지**: `units.ts` 의 `art` 필드가 있으면 우선 → 나중 라스터/외주 아트로 무손실 교체.
- (원하면) 세션에서 AI invoke 가 열리면 라스터 버전도 시도 가능.

## 6. 기술 원칙

- **인라인 SVG only** (외부 fetch 0) → Capacitor 엄격 CSP 안전.
- **테마 대응**: 색 도형/투명 배경이라 라이트·다크 모두 자연.
- **데이터 주도**: 아트는 `art` 필드로. 새 유닛/보스 추가 시에도 렌더러 불변.
- 리치화가 필요하면 스프라이트 아틀라스(WebP) + 지연로딩으로 확장(엔진 무관).
