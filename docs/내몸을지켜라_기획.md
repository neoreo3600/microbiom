# 《내몸을 지켜라》 — 머지 디펜스 (방향 전환)

## 왜 피벗했나
방치형 미터-회복 게임은 손맛은 있으나 **직관적이지 않고 "이기는 감각"이 약했다**.
→ **머지 + 거점 디펜스**로 전환: 즉시 이해되고(몸을 지킨다), 합체(2048식)의 도파민 루프가 강력.

## 프레이밍 결정 (중요)
이 앱은 **오직 재밌고 직관적인 아케이드 게임**으로 간다. 치유·존엄 프레이밍은 별도 앱의 몫으로
분리. 유해균·염증세포·암세포는 물리치는 적으로 다룬다(면역이 실제로 하는 일). 앱 내에는
**"게임이며 의학 정보가 아니다"** 최소 한 줄만 유지.

## 코어 루프 (MVP — 구현 완료)
- **거점 방어**: 위에서 내려오는 적을 5열 그리드에서 세포로 막고, 하단 거점(내 몸)을 지킨다.
- **놓기**: 빈 칸을 탭 → 호중구(에너지 소비). 에너지는 시간당 재생 + 처치 보상.
- **합체**: 같은 종류·티어 세포를 **드래그해 겹치면 승급**. 합치면 체력 풀 회복.
  - 면역 트리: **호중구 → 대식세포 → T세포 → NK세포** (강해질수록 공격·사거리·체력↑)
- **성벽**: 미생물 성벽(바이오필름)을 놓아 적을 막는 방어 구조물.
- **웨이브**: 4웨이브(유해균 → +염증세포 → 다수 → 보스 **암세포**). 전 웨이브 방어 = 승리.
- **패배**: 거점 HP 0.

## 구현 (src/defense/)
- `content.ts` — 세포 티어·적·웨이브 데이터(밸런스 상수). 새 적/티어/웨이브 = 여기만.
- `engine.ts` — 순수 실시간 전투 시뮬(step): 스폰·이동·사격·투사체·합체·승패. COLS×ROWS.
- `game.ts` — 캔버스 렌더 + 포인터 입력(놓기/드래그/합체) + HUD + RAF 루프. 사운드/이펙트는 `game/juice.ts` 재활용.
- `main.ts` — 우상단 **🛡 지켜라** 토글로 진입(기존 방치형/디버그와 공존).

## 검증
- tsc·vite build 통과. 브라우저 구동: 시작→호중구 배치→드래그 합체(호중구→대식세포 확인)→
  유해균 웨이브 하강·HP바·거점 렌더 무에러.

## 상용화 루프 (구현 완료)
- **장기별 특성(패시브)**: 장=에너지재생+50% / 간=처치보상+60% / 폐=사거리+1 / 심장=공격속도+25%.
  웨이브마다 장기가 바뀌어 전략도 바뀜. HUD에 현재 특성 표시.
- **웨이브 사이 강화 상점(메타 성장)**: 클리어 시 면역포인트(IP) 획득 → 상점에서 구매.
  💥공격+15% · ⚡에너지재생+2 · ❤️거점HP+30 · 🦴골수이식(기지 자동생산). 구매마다 비용↑, 이번 판 지속.
- **기지 자동 생산(골수)**: 방어 구역 빈칸에 호중구 주기적 자동 생성(강화 시 간격↓) — 아이들/기지 운영감.
- 루프: **방어 → 클리어 보상(IP) → 상점 강화 → 다음 장기** = 상용 디펜스 핵심 사이클.

## 영구 성장 & 캠페인 확장 (구현 완료)
- **8웨이브 캠페인**: 난이도 곡선 + 중간·최종 보스. 신규 적 **바이러스**(빠른 스웜) 추가(캡시드 실루엣).
- **영구 성장(로그라이트 메타)**: 판 종료 시 **항체(antibody)** 획득(클리어 웨이브·처치·승리 보너스),
  localStorage 영구 저장. **로비**에서 6종 영구 강화 구매(시작에너지/거점HP/시작공격/재생/골수보유/시작IP).
  → 판을 거듭할수록 강해지는 재도전 훅.
- **2단 성장 구조**: 판 내부 IP 상점(웨이브 사이) + 판 밖 항체 로비(영구) = 상용 로그라이트 표준.
