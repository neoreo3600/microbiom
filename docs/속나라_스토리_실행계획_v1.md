# Part A · 게임 스토리

## 0. 로그라인

> **한 사람의 몸속에 깃든 이름 없는 손길이 되어, 무너진 생태계("속나라")를 순환·정화·재생으로
> 되살리고 — 그 사람이 스스로 균형을 되찾기 시작하면, 다음 사람에게로 이주한다.**

치료가 아니라 **정비**의 이야기다. 적을 죽이는 게 아니라 **균형을 되돌리는** 이야기다.

## 1. 톤 & 장르 프레이밍

- **사이언스 엔터테인먼트 판타지.** 몸속 생태계가 "어떻게 작동하는지"를 체험하는 은유의 세계.
- **톤:** 차분함 · 희망 · 과학적 경외. 자극·공포·재촉이 아니라 **돌봄과 축적**의 정서.
- **비협상 가드레일(§0):**
  - 치료 시뮬레이션·의료 대체 서사 아님. **"이 게임은 의학적 조언이 아니며 실제 질병은 의료진의 진단·치료가
    필요하다"** 를 게임 내 상시 노출.
  - 특정 질병이 게임/생활습관만으로 낫는다는 표현 금지. 자해·위기 묘사 금지. 실제 제품/브랜드/치료법 광고성 삽입 금지.
  - 민감 영역(우울·암)은 **존엄·희망의 방향으로만**. 낙인 금지.

## 2. 세계관 — "속나라"란 무엇인가

한 사람의 몸은 하나의 **나라(생태계)** 다. 이 나라의 이름이 **속나라**.

- **뿌리(宗):** 장내 마이크로바이옴. 모든 흐름이 여기서 발원한다(만류귀종). 다양성이 나라의 국력.
- **네 관문:** 장벽·염증·대사·자율신경 = 플레이어가 다스리는 **4대 미터(숲·물길·온기·빛)** 의 실체.
- **여섯 지방(오행 월드):** 목·화·토·금·수·상화. 각 장부 계통이 하나의 지역이며, 고유한 감정(빌런)·오미(자원)·조직을 가진다.
- **하류의 증상들:** 40여 질병은 겉모습만 다른 하류의 그림자. 거슬러 오르면 소수의 뿌리에서 갈라진다.

속나라는 평화로울 때 스스로 순환한다. 무너지면 — 균형의 붕괴가 **화신(보스)** 으로 나타난다.
보스는 침입자가 아니라 **뒤틀린 균형 그 자체**다. 그래서 "죽여서" 이기는 게 아니라, **되돌려서** 이긴다.

## 3. 플레이어 — 당신은 누구인가

당신은 의사가 아니다. 약도 수술도 없다.
당신은 속나라에 깃든 **이름 없는 손길** — 생태계를 돌보는 정원사이자 사령관이다.

> 당신에게는 **네 개의 손길**이 있다. 그 진짜 이름은 **장수온심(腸水溫心)**.
> **숲**(기르다) · **물길**(흐르다) · **온기**(지피다) · **빛**(밝히다).

이 네 손길로 무너진 나라의 다이얼을 굴린다. 당신이 부리는 것은 무기가 아니라 **자연의 세 원리** —
**순환(막힌 것을 열고) → 정화(쌓인 것을 비우고) → 재생(생태계를 다시 키운다).**

> 판타지의 핵심(§6): *"의식이 몸속 생명체의 창조주"* — 플레이어는 명령하는 자가 아니라 **돌보는 자**다.
> 승리는 정복이 아니라 **항상성의 회복**이며, 그 순간 나라는 당신 없이도 스스로 돌기 시작한다.

## 4. 핵심 서사 구조 — 숙주, 이주, 그리고 메타 아크

### 4.1 숙주 — 이 보스는 "사람"이다

각 속나라의 바깥에는 **한 사람**이 있다. 이야기의 심장은 여기 있다.

- **김성호, 54세** — 야식으로 하루를 닫는 가장. (당뇨 · 토·비위)
- **이지현, 34세** — 아침마다 손이 뻣뻣해 아이를 안기 힘든. (자가면역 · 목·간담)
- **박준영, 29세** — 몇 달째 색을 잃고 방에서 나오기 힘든. (우울 · 마음의 숲)

속을 정비할수록 **바깥의 삶이 한 컷씩 회복된다.** 계단이 덜 숨차고, 다시 아이를 안고, 아침에 창을 연다.
이 한 컷이 보상이자 서사의 절정이다. (숙주 이름·사연은 스테이지마다 교체 가능한 데이터)

### 4.2 이주(移住) — 다음 사람에게로 = 프레스티지

한 사람의 속나라가 항상성을 되찾으면, 당신은 **이주**한다. 다음 사람에게로.
떠나며 당신은 그 나라에서 배운 **지혜(genes = 영구 modifier)** 를 안고 간다. 그래서 다음 나라는 조금 더 수월하다.

> 이주 = 방치형의 프레스티지. 리셋이지만 상실이 아니다. **배움은 남는다.**
> "완치하고 떠난다"가 아니라 "**스스로 돌 수 있게 되었으니** 다음으로 간다"는 겸손한 서사.

### 4.3 메타 아크 — 점점 더 깊은 뿌리로

이주를 거듭할수록 당신은 더 얽힌 연쇄(만류귀종)와 더 근원적인 영역을 마주한다.

1. **입문 — 몸의 나라들:** 당뇨·자가면역처럼 "직관이 틀리는" 함정을 배운다. (더 만들면/때리면 지는 법)
2. **심화 — 마음의 숲:** 우울·불안. 식(識)이 주역이지만 **몸을 먼저 고쳐야 마음이 열린다.** 장-뇌축의 정수.
3. **심연 — 최종 판타지:** 암 계열. "죽이기"가 아니라 **환경을 교정해 굶기고 감시망을 세운다.** 순수 은유로만.

궁극의 메시지: **몸과 마음은 하나의 회로다. 증상을 쫓지 말고 뿌리를 정비하라. 그러면 나라는 스스로 균형을 되찾는다.**

## 5. 게임 루프와 서사의 결합

방치형이라는 장르가 곧 메시지다. **회복은 즉각적이지 않다 — 시간과 축적이 필요하다.**

| 게임 메커니즘 | 서사적 의미 |
|---|---|
| 방치(idle) 중 생산·회복 | 몸이 스스로 회복하는 시간. 당신이 자리를 비워도 기른 생태계는 일한다. |
| 오프라인 보상 | *"숙주가 자는 동안 균들이 청소했어요."* 수면·오토파지의 게임화. |
| 순·정·재 3페이즈 | 막힌 것을 열고 → 쌓인 것을 비우고 → 다시 키우는, 회복의 순서. |
| 항상성 승리 | 증상 제거가 아니라 "스스로 균형을 되찾기 시작함". |
| 만류귀종 종속 | "장부터"가 잔소리가 아니라 **수학적으로 유리한 전략**. 근원 정비의 체득. |
| 이주(프레스티지) | 배움을 안고 다음 사람에게. 겸손한 반복. |

## 6. 서사 톤 가이드 (작성 규칙)

- **승리 문구:** "없앴다/이겼다" ❌ → "**스스로 균형을 되찾기 시작했다**" ⭕
- **숙주 묘사:** 증상의 고통을 전시하지 않는다. **회복의 방향**으로만 한 컷.
- **우울/암:** 의지·성격 결함이 아니라 **무너진 생물학적 지반의 문제**로. 자해·위기 없음. 희망으로만.
- **과학 프레이밍 유지:** 한의학·기능의학은 "몸을 보는 해석 틀"로 소개하되, 임상 치료법으로 단정하지 않는다.
- **상시 노출:** 의료 디스클레이머 배너 + 위기 시 전문 도움 안내(민감 월드 진입 시).

## 7. 세계관 용어집

| 용어 | 뜻 |
|---|---|
| 속나라 | 한 사람의 몸속 생태계(나라) |
| 네 손길 · 장수온심 | 플레이어의 4미터: 숲(腸)·물길(水)·온기(溫)·빛(識/心) |
| 뿌리노드 · 宗 | 마이크로바이옴. 만류의 발원, 나라의 국력(diversity) |
| 만류귀종 | 하류(증상)는 상류(뿌리)의 그림자. 뿌리를 고치면 연쇄가 역류 |
| 순·정·재 | 순환→정화→재생. 모든 보스전의 3페이즈이자 회복의 원리 |
| 화신(보스) | 뒤틀린 균형이 형상화된 존재. 질병 = 미터 벡터의 붕괴 |
| 숙주 | 속나라 바깥의 실제 사람. 회복의 이유 |
| 이주 | 다음 사람에게로. 프레스티지(리셋+영구 지혜 계승) |
| 오염(염증) | 크로스-빌런 자원. 대부분 보스가 이걸로 자가 회복 |
| 항상성 | 승리 조건. 균형 밴드로의 자율 복귀 |

# Part B · 실행 계획 (로드맵)

## 현재 상태 — 완료된 것 (M1–M3 완료, M4 진행 중)

이미 구현·검증 완료(엔진 단언 + 실브라우저 체크 + `npm run playthrough` 전 보스 🟢):

- ✅ 5 프리미티브 데이터 주도 엔진 + `break_infinity`(1e100+) + 세이브/오프라인 무손실
- ✅ 4미터(숲·물길·온기·빛) + 염증·해독 연속 시뮬레이션 + 되먹임 고리(장-뇌축)
- ✅ 뿌리노드(마이크로바이옴) + 만류귀종 종속(diversity↑ → 시작미터↑·염증regen↓)
- ✅ 보스 6종(당뇨·자가면역·우울·대장암·지방간·불안) — 4대 아키타입 + 순·정·재 게이팅 + 항상성 승리 + 허실 분기
- ✅ 숙주 캠페인 5명 + 이주 루프(genes 계승) + 오행 6월드 + 오미 자원 경제 + 히어로 유닛 10종
- ✅ 실제 게임 UI(4탭 + 온보딩 + 애니메이션) + 디버그 인스펙터(미터·뿌리노드·보스전·만류귀종 트리·난이도 그래프)
- ✅ Capacitor 하이브리드 셸 + 광고 추상화(웹 스텁 / 네이티브 AdMob) + 네이티브 빌드 가이드

## 마일스톤

### M1 — 플레이 루프 성립 (핸드오프 P1) ✅ 완료
**목표:** "한 숙주 클리어 → 이주 → 다음 숙주"가 실제로 도는, 플레이 가능한 최소 게임.

- ✅ M1-1 숙주 캠페인 + 클리어→이주→다음 숙주 루프 (지혜 계승 · 몸 리셋)
- ✅ M1-2 이주 보상(genes) 공식 튜닝 (기본+뿌리품질+숙주깊이+그라인드)
- ✅ M1-3 다음 숙주 보스 난이도 미리보기 (뿌리 재건 시 실시간 완화 = 만류귀종 체감)
- ✅ M1-4 숙주 이벤트(날씨) 혼돈 엔진 (야식·스트레스·수면… 즉시효과+임시 modifier)
- ✅ M1-5 승리 시 영구 보상(치유 지혜 배지, 이주해도 유지) + 도감 UI
- ✅ M1-6 오행 6월드 World config화 (장부·감정·오미·주관 조직)
- ✅ M1-7 우울 보스(강요형) + 식(識) 잠금 시그니처 + 박준영 숙주
- ✅ M1-8 밸런스 회귀 가드 (`npm run playthrough`)
- ✅ M1-9 암(은신형) 보스 — 4대 아키타입 완성 + 연료·감시 종양 모델
- **수용 기준 충족:** 뿌리 재건 시 하류 난이도↓ 수치 확인 · 순·정·재 게이팅 작동 · 이주 루프 성립.

### M2 — 콘텐츠 폭 (유닛/히어로 + 자원 경제) ✅ 완료
**목표:** 시스템의 폭을 증명하는 다양한 손맛. (아키타입 4종·6월드·날씨는 M1에서 선행 완료)

- ✅ (선행) 보스 아키타입 4종 · 오행 6월드 · 숙주 날씨 이벤트
- ✅ M2-1 히어로 유닛 레이어 (유익균·Treg 등 10종 = 전투 지원 Modifier 소스, 보스 태그·스택·이주 유지)
- ✅ M2-2 오미(五味) 자원 경제 (월드별 회복 자원 축적·소비, 맛별 효과)
- ⬜ 암 계열 캠페인 편입 결정 (§0/§8 민감성 검토 후 — 현재 BOSSES/디버그로만 접근)
- **수용 기준 충족:** 신규 유닛/자원이 config만으로 추가(engine 0줄).

### M3 — 서사·연출 경량 레이어 ✅ 완료
**목표:** 숫자에 "이유"를 입힌다. 아트는 여전히 최소.

- ✅ (선행) 숙주 카드(이름·사연·회복 컷) — M1-1
- ✅ M3-1 되먹임 고리 실시간 시각화 (🔴 돌아감/⚪ 정지 + 강도 + 끊는 지점)
- ✅ M3-2 민감 보스전 디스클레이머 강화 (우울·암, §0 비협상)
- ✅ M3-3 승리 결과 화면(리절트 카드) — 회복 컷 + "스스로 균형 회복" 프레임 + 배지/genes/도감
- ✅ M3-4 만류귀종 트리맵 (뿌리→관문→월드→증상 라이브 히트색)
- **수용 기준 충족:** 승리 시 "스스로 균형 회복" 프레임 · 가드레일 문구 상시.

### M4 — 이식 & 수익화 (핸드오프 P2) 🔶 진행 중 (스택 확정 · 실기기 연동만 남음)

## 밸런스 스냅샷 & 리뷰 메모 (`npm run playthrough`)

올바른 순·정·재 순서로 완주 시뮬 (한 iter=0.5s, 손길 최적 반복). **C 밸런스 대패스 반영(HEAL_TUNING 소폭 하향):**

| 보스 | 완주 iter | 관찰 |
|---|---|---|
| nafld | 11 | 신규·경량 — 지방간, 초반 교육 이후 배치 |
| anxiety | 12 | 신규 — 불안, 淸熱 없이 정화→재생 진입 |
| depression | 17 | 식 잠금이 지반 선행을 강제, 지반 회복 후엔 빠름 |
| diabetes_T2 | 18 | 교육형 — 첫 숙주, 완만한 상승 |
| colon_cancer | 43 | 은신형 — 지속 감시 필요, 적절히 김 |
| autoimmune_RA | 55 | 최난 — 淸熱 후 온기 회복 대기가 길이를 만듦 |

- **C-1 오프라인 오미 감쇠:** `OFFLINE_TASTE_FACTOR=0.15` 도입. 오프라인 오미는 능동 대비 15%만 축적(4h ≈ 86, 이전 1152에서 대폭 하향). 능동 보스전이 항상 유리 — "자면서 이기기" 방지. 엔진 단언으로 회귀 가드(`gained < naiveActive*0.5`).
- **C-2 오미 축적률:** `TASTE_ACCRUE_RATE 0.08→0.04`. 사용 간격(~25s/회)이 의미있게 벌어져 오미 사용이 전략 선택이 됨.
- **C-3 손길 수치 정리:** 순환/정화/재생 delta를 소폭 낮춰(초반 보스 11~18iter) 지나치게 빠른 클리어를 막되 난이도 순서(교육<신규<우울<암<자가면역)와 winnability 유지.
- **관찰 1:** 시뮬상 절대시간은 여전히 짧다(손길 delta가 UI 체감보다 큼). **손길 쿨다운/체감 곡선**은 M4 이후 실기기 플레이테스트로 튜닝 권장.
- **관찰 2:** naive "다 눌러"는 autoimmune 미완주(온기 과냉각) — 허실 분기가 회귀 가드로 고정됨. 유지 권장.
- **관찰 3:** genes 공식은 현행 유지(C에서 미변경).

## 당신이 정해줄 지점 (내가 진행하되, 방향만)

1. **이식 스택:** Unity 풀포팅 vs 웹(현 TS 엔진)+Capacitor/WebView 하이브리드로 광고 SDK. (엔진 로직은 이미 TS라 하이브리드가 빠름 — 기본값 제안)
2. **아트 방향성:** M3에서 최소 픽토그램/컬러바 유지 vs 일러스트 도입 시점.
3. **서사 밀도:** 숙주 카드=짧은 텍스트 컷(권장·경량) vs 대화/연출 확장.
4. **초기 콘텐츠 범위:** 소프트런치 시 보스 몇 종·월드 몇 개로 낼지.

→ 지정 없으면 각 항목 **기본값(괄호)** 으로 진행한다.
